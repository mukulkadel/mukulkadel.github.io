--- layout: app title: SQL Formatter permalink: /apps/sql-formatter/ description: Pretty-print SQL queries with keyword casing and clause indentation, entirely in your browser. ---

Paste a SQL query to format it. This is a best-effort formatter built with regex-based rules (not a full SQL parser) — it handles common SELECT/JOIN/WHERE/GROUP BY style queries well, but unusual syntax may not format perfectly. Everything runs locally in your browser.
